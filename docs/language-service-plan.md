# Vue 2 语言能力补齐清单

保留现有轻量跳转；项目语义分析按需进入独立工作线程。扩展入口与工作线程均使用 CommonJS，继续验证 JoyCode。业务测试文件只读。

| 能力 | 验收场景 | 状态 |
| --- | --- | --- |
| Vue 成员大纲 | 大文件按 data / methods / computed 定位 | 待接入 |
| 悬停、参数与 JSDoc | 本地及导入函数的注释、参数、类型 | 待接入 |
| mixin / extends | 本地覆盖优先、跨文件继承成员 | 待接入 |
| 引用查找 | 模板与脚本引用，排除同名局部变量 | 待接入 |
| 自动导入 | 补全导出符号并插入对应 import | 待接入 |
| 类型检查 | 脚本及模板真实类型错误的原文件范围 | 原型已验证 |
| 安全重命名 | 语义定位、跨文件编辑、拒绝不确定位置 | 待接入 |
| HTML / CSS | 补全、悬停、诊断、格式化、颜色、链接 | 待接入 |
| 全局注册 | 静态 Vue.component / Vue.prototype | 待接入 |
| Vuex / $refs | 静态映射、store 路径及组件 ref 成员 | 待接入 |
| 组件事件 | 父组件监听名称到子组件 $emit | 待接入 |
| 循环与插槽变量 | 解构、嵌套遮蔽、准确声明范围 | 待接入 |

项目使用的 Vue 类型决定可推断的深度；动态注册、运行时字符串和没有声明的第三方类型不能保证推断。不要通过把未知值改成 any 来声称完整支持。重命名只应用语义服务确认的范围，不做全项目字符串替换。
