# 0.21.1 修复与 JoyCode 验证

日期：2026-10-25。环境：macOS arm64、Node v24.21.0、JoyCode IDE 3.0.12，宿主 API 版本 1.98.2。

## 修复范围

- 组件补全使用解析后的标签起点，并区分引号内的比较符与真正的标签边界。`<`、`>`、`<=`、`>=` 不再使后面的属性、事件和枚举值上下文失效。
- 无配置的 inferred project 在文件发现前启用 `allowJs`。非 Git 普通目录中的未打开 JS 文件可参与全局注册跳转与自动导入，并继续遵循 `.gitignore`。
- 移除 JS/TS 目录去重中的嵌套公开补全查询。相对路径和配置映射由启用的原生服务提供目录；扩展独有的别名、资源相对路径回退以及关闭原生路径建议时由扩展提供目录。资源文件仍由扩展补充。
- 隔离宿主测试的工作区显式关闭自动保存，避免 JoyCode 默认 `afterDelay` 改变“配置未保存”的测试前提。
