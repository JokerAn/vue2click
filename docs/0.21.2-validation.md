## 改动范围

- 主入口和语言工作线程通过相对路径加载同一份随包 `dist/typescript.cjs`，继续使用 CommonJS。
- TypeScript 标准类型声明完整保留；本次未修改 `src/` 中的功能代码或依赖版本。

## 复现

```sh
node --test test/build.test.js
npm run package
git diff --check
```

完整宿主套件可用以下命令复现，仍需注意上述未通过项。`TMPDIR=/tmp` 避免 macOS 临时目录过长导致编辑器 IPC socket 无法创建：

```sh
TMPDIR=/tmp \
VSCODE_EXECUTABLE_PATH="$PWD/.vscode-test/vscode-darwin-arm64-1.143.1/Visual Studio Code.app/Contents/MacOS/Code" \
npm run test:vscode

TMPDIR=/tmp \
VSCODE_EXECUTABLE_PATH="$PWD/.vscode-test/vscode-darwin-arm64-1.90.0/Visual Studio Code.app/Contents/MacOS/Electron" \
npm run test:vscode
```
