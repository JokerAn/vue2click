# 0.21.3 标准库压缩验证

日期：2026-10-25。环境：macOS arm64、Node v24.21.0、TypeScript 5.9.3。

## 实现范围

- 将当前 TypeScript 依赖的全部 100 份 `lib*.d.ts` 逐文件 Brotli 压缩，生成 `dist/typescript/*.d.ts.br`。
- 语言工作线程在读取标准库时解压，通过原有 `disk` 快照缓存复用结果；存在性检查不解压，服务释放时清空缓存。
- 编译器继续固定版本随包提供；构建自动枚举声明文件，没有删除 DOM、Web Worker、ESNext 或声明注释，也没有改用宿主 SDK。
- 读取层仅接管指定标准库目录下的声明。普通源码与开发环境原始声明沿用原读取方式，损坏的压缩文件显式报错。
- 本次没有修改路径补全、编辑光标或其他功能逻辑，也没有新增运行依赖。

## 新旧实际 worker 的性能样本

从 0.21.2 与 0.21.3 VSIX 各自解包启动真实 worker，使用同一临时 Vue 2 项目。每版交替运行 5 次，每次记录启动至首次类型查询，并继续执行 50 次查询。

| 指标 | 0.21.2 | 0.21.3 |
| --- | ---: | ---: |
| 启动至首次类型结果中位数 | 550.855 ms | 621.349 ms |
| 每轮连续查询中位数的中位数 | 4.295 ms | 3.665 ms |
| 已加载快照数量 | 74 | 74 |
| 查询后 worker 堆内存中位数 | 148.939 MiB | 146.538 MiB |

这组有限样本里，首次请求增加约 70 ms，连续查询没有显示变慢。没有强制 GC，堆内存数字不是内存峰值或降低内存的承诺；样例也不代表真实大项目或编辑器绘制耗时。

额外插桩的两次新 worker 首次请求共解压 51 份声明，解压自身累计分别约 4.762 和 4.518 ms。文件读取、模块加载和类型程序构建也参与总耗时，因此不能将首次请求的全部差值归因于解压，或宣称压缩没有冷启动成本。

## 验证边界

本版针对压缩读取验证核心语言服务，没有将历史完整宿主套件的目录数量或光标断言问题纳入修改。上轮完整套件的已知未通过项和原打包方式对照见 [0.21.2 验证记录](0.21.2-validation.md)。

运行时仍需将使用到的声明还原为文本和语法树；安装体积下降不代表运行内存同比下降。解压发生在工作线程首次读取标准库时，线程重建后需要重新加载。
