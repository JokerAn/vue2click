# 0.16 日常编辑能力验收

本轮保留 0.16.0 版本和已有性能修复，不修改用户设置或暂存区，不增加开页项目扫描。

| 能力 | 必须验证的行为 | 状态 |
| --- | --- | --- |
| 组件 props 与事件 | 类型、必填、默认值、注释、明确可选值、静态事件补全和悬停 | 已实现；单测与 VS Code 宿主通过 |
| 脚本阅读辅助 | Vue 脚本折叠、真实同符号高亮、逐级选区 | 已实现；纯逻辑与 VS Code 命令通过 |
| 一次性检查 | 命令检查当前文件，默认不诊断，不改变自动诊断开关 | 已实现；宿主确认默认无诊断，手动命令产出诊断 |
| 组件自动导入与注册 | 选择模板候选后生成 import 和 components，别名冲突与已有注册不误改 | 已实现；宿主补全包含额外编辑，单测覆盖冲突 |
| 精选快速修复 | 缺失 import、整理和移除未使用 import；只产生用户触发的编辑 | 已实现；宿主调用补 import 与 source 操作 |
| 组件库元数据 | 只读取项目已安装库的匹配版本数据，支持项目自定义数据、Element UI 2 常用组件和 Vue Router 3 | 已实现；测试证明读取而不执行包入口 |
| 标签与 Emmet | 独立安装后闭合标签、模板和样式缩写，不在字符串或脚本污染补全 | 已实现；VS Code 宿主验证闭合和 Emmet |
| 整文件格式化 | 模板、脚本和样式均有编辑；遵循格式设置，可关闭以让外部格式器接管 | 已实现；宿主验证脚本与嵌入区均生成编辑 |

每项需通过对应单测及真实编辑器命令验证后才能标记完成。外部源码、模板预处理器和运行时动态协议仍不扩大支持范围。
