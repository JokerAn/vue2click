2026-10-25，macOS arm64、Node v24.21.0：

- 最终 `npm run package`：244 项单测，239 通过、5 跳过、0 失败；入口加载和 Vue 2 worker 构建检查通过。

- VSIX 的 JSON 与 XML 版本均为 0.20.0，ZIP 完整性通过；包内依赖许可说明为 83,083 字节，包含 29 个依赖条目。

## 回归覆盖

- 明确默认导出的插件对象、对象方法、函数属性、单独 install 声明和 Plugin.install 赋值。
- 普通同名函数、未导出插件、options 参数、局部变量遮蔽不会产生全局注册。
- 全局注册支持首次按需建立，同版本复用，以及单文件失效。项目集成测试覆盖未保存编辑、关闭恢复磁盘、磁盘修改、新增和删除。
- 循环 ref 不按单一实例跳转；其他 this 作用域不借用 Vue ref。
- JSDoc 提供者覆盖跨文件引用范围、参数类型、箭头函数、嵌套类型、多行说明、过期请求，以及静态路径不请求项目 worker。
- 多个间接来源不借用首个候选说明；唯一 prototype 成员显示来源。
- 同版本重建静态索引时，嵌入文档不重复积累。文档版本变化仍失效，不声称跨版本复用解析树。
- 许可清单覆盖符号链接、绝对路径和 node_modules 之外的实际依赖输入。

## 可复现命令

```sh
npm run package
npm run benchmark:registry
VUECLICK_READ_TEST_ONLY=1 \
VSCODE_EXECUTABLE_PATH='/Applications/Visual Studio Code.app/Contents/MacOS/Code' \
npm run test:vscode
```

只读 API 专项不依赖窗口焦点，使用真实扩展宿主调用悬停提供者。完整宿主测试保持原有焦点检查，未因本轮新增专项而放宽。

增量基准在内存构造 2,000、5,000、10,000 个候选文件：首次分别加载全部候选；同版本再次查询为 0；修改一个普通文件或插件文件后为 1。基准只证明候选加载次数，仍需枚举文件名并合并贡献，不包含磁盘、编辑器通信或类型程序耗时。

## 限制

旧业务绝对路径相关的 5 项单测在样例不可用时跳过；没有冒用新路径替换具有固定行号断言的旧样例。
本机只读 API 专项通过不代表物理 Tab、建议列表、撤销、完整宿主或 JoyCode 已验证。
首次全局注册查询仍会枚举候选源码；不执行插件代码，因此默认导出安装钩子是静态声明，不能证明运行时调用。
尚未改成跨版本的 SFC 块增量解析，也未改动正在执行的 TypeScript 任务中断策略。
